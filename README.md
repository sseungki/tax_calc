# 아이 20년 복리 & 증여세 시뮬레이터 (tax_calc)

자녀의 나이와 투자 조건(초기 투자금, 월 적립액, 기대 수익률 등)을 입력하면, 만 20세 시점의 예상 자산과 증여세 없이 줄 수 있는 한도 및 시점을 한 번에 보여주는 웹 계산기입니다.

## 🌟 주요 기능
- **직관적인 자산 성장 그래프**: 납입 원금과 평가액의 변화를 그래프로 한눈에 확인
- **증여 공제 주기 시각화**: 미성년자(10년간 2,000만 원) 및 성년(10년간 5,000만 원) 공제 한도 자동 계산 및 소진율 표시
- **한도 초과 경고 및 대안 제시**: 한도를 넘는 시점을 그래프와 알림으로 즉각 파악
- **배당 재투자 비교**: 배당 재투자 여부에 따른 20년 뒤 자산 차이 시각화
- **반응형 프리미엄 다크 테마 UI**: 모바일(1단)과 데스크톱(2단) 환경 모두에 최적화된 디자인

## 🛠️ 기술 스택
- HTML5, CSS3 (Vanilla CSS, CSS Variables)
- Vanilla JavaScript (순수 함수 계산 엔진과 UI 컨트롤러 분리)
- [Chart.js](https://www.chartjs.org/) (그래프 시각화)

## 🚀 로컬 실행 방법
이 프로젝트는 서버리스 정적 웹페이지로 구성되어 있습니다. 아래 명령어로 로컬 서버를 실행하여 바로 확인할 수 있습니다.

```bash
npx -y http-server . -p 8080 -c-1
```
이후 브라우저에서 `http://localhost:8080`에 접속하여 확인할 수 있습니다.
